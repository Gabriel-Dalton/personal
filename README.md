# personal

An earlier version of the personal site, from April 2025. Superseded. The current site is https://gabrieldalton.com.

What survives here is a fragment rather than a working site. The root holds a `CNAME` for portfolio.gabrieldalton.com and little else, and the only page is a single `home.html` sitting under a doubled `personal-website-old-main/personal-website-old-main/new/` path, left behind by unzipping an archive into the repo. With no `index.html` at the root, that domain reaches GitHub Pages and returns a 404.

`home.html` is one file with its CSS inlined: a full height photo banner, an About Me section, and a row of logos for organizations worked with. Its image paths assume the doubled directory, so it renders in place and nowhere else.

Kept for history. Nothing in here is current.
